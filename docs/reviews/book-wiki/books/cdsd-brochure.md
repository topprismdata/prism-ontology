# CDSD Brochure
## 定位
Direct Store Delivery（直达门店配送）体系手册：司机-线路-门店执行一体化模式介绍（p.1 出现 "Direct Store Delivery" 主题）。
## 核心框架/贡献
DSD 模式：配送与店内执行合一，司机即终端信息采集者。
## 对销售管理领域/本体评审的价值
DSD 是 VisitRecord（车载打卡/车销）与 VisitMode（车销直送）的业务原型；本体 VisitMode 注释里的"车销直送"直接对应本模式。
