# Sales Territory Alignment: A Review and Model
## 定位
辖区对齐（alignment）研究的奠基性综述+模型。把"辖区设计"形式化为对齐问题：把账户集合分配到辖区，平衡工作量（workload）与潜力（opportunity），并综述此前全部 OR 文献。
## 论文结构
- p.2 §1 Introduction（问题动机）
- p.3 §2 A Framework for Sales Territory Alignment and a Review（对齐框架+文献综述）
- p.7 §3 A Model for Sales Territory Alignment（数学模型）
- p.16 §5 LP 与次梯度方法对比
- p.18 §6 Implementation Issues（实施问题）
- p.20 §7 Conclusion
## 核心框架/贡献
1. 对齐双目标：等分工作量 + 等分销售潜力（p.3-7）
2. 基本对齐模型：账户→辖区的整数规划（p.7）
3. 求解方法对比：LP vs subgradient（p.16）
4. 实施视角：模型到组织落地的差距（p.18）
## 对销售管理领域/本体评审的价值
"Territory = workload 与 opportunity 的平衡单元"这一权威定义应进入本体的 Territory 类语义；本体把 Territory 仅建为管理实体，未承载 workload/potential 目标属性与 account assignment 关系的粒度（账户级而非区域级）。
